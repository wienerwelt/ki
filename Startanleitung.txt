DEVELOPMENT (lokaler Server = Laptop)
1.Schritt
1.1 Docker Desktop-Anwendung auf Ihrem Computer gestartet sein
1.2 Redis-Server starten:
1.3 docker run -d --name mein-redis-server -p 6379:6379 redis
	wenn der Container bereits existiert, starten Sie ihn mit:
1.3 docker start mein-redis-Server (Lokal)
	wenn Redis direkt installiert:
1.3 redis-server

(Lassen Sie dieses Terminalfenster geöffnet)

Schritt 2: Backend starten (API-Server & Worker)
2.1 cd pfad/zu/deinem/projekt/backend (cd backend)
Terminal 1) npm run dev:worker
Terminal 2) npm run dev

Schritt 3: Frontend starten
3.1 cd pfad/zu/deinem/projekt/frontend (cd frontend)
Terminal 3) npm run dev

Zusammenfassung
Frontend http://localhost:5173

PRODUKTIV (Ionos)

1.2. Daten (frontend) in den Ordner /httpdocs/dashboard/frontend/ überspielen

oder
